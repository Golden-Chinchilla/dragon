# Scrollytelling 3D Dragon

Single-page scrollytelling experience built with React Three Fiber and Three.js.
The project focuses on camera/animation choreography across scroll-driven sections.

## Tech Stack

- React 19 + TypeScript
- Three.js + @react-three/fiber + @react-three/drei
- Tailwind CSS v4
- Webpack 5
- Yarn 1.x

## Getting Started

```bash
yarn
yarn dev
```

Open the dev server URL printed in the terminal.

## Scripts

- `yarn dev`: start the dev server
- `yarn build`: production build

## Notes

- Models are served from `public/models`.
- Section configuration lives in `src/config/sections.ts`.
