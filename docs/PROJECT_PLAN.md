# ODONATA 项目记录

## 当前方向

2026-10-05 按用户要求清理旧项目，构建独立机械蜻蜓。用户随后指出初版结构过于简单，并提供机械蜜蜂视频作为精细程度参考；第二版针对装配层次、薄壳构造、光学单元和翼脉重新建模。保留独立作品方向，不恢复旧庭院和地图。

## 第二版已完成

- 胸腔改为底层电机、连续螺旋铜线绕组、齿轮层和轴承桥板；配有侧面检修板、百叶缝、沉头紧固件和刻度。
- 齿轮由独立方块齿改为连续切削轮廓，包含窄齿根、斜齿侧、薄轮辐、阶梯轮毂。齿形是艺术化构造，不是制造用渐开线。
- 复眼改为 566 个密排的六角光学单元，保留独立框边和棱面透镜；头部添加虹膜镜组、锁紧边圈和分节触须。
- 四翼使用确定性 Voronoi 多边形分区与分叉主脉，减细翼脉，细化双层翼根叉板、轴承和配重，并缩短翼展以提高机身辨识度。
- 十节腹甲改为左右分片薄壳，具有真实厚度、接缝、内脊、细拉杆、散热片与检修槽。
- 六足改为双杆叉架、轴承关节、波纹护套、细活塞杆与分节抓钩；线缆采用三股几何绞线。
- 加入屏幕空间 GTAO 接触遮蔽，帮助区分叠层板件和轴承；透明翼膜和地面阴影平面不参与该深度通道。保留抗锯齿和单次输出色调映射。
- 保留全貌 / 传动 / 翼脉 / 俯视、复眼观察点、旋转缩放、结构展开、暂停与镜头自动旋转。动画直接更新 Three.js 对象。

## 当前资产

- 可编辑源网格零件：5,506（包括复眼单元和翼脉分段，数量不等同于功能机械零件数量）。
- 网页网格：147；三角形：375,572；PBR 材质：9。
- GLB：8,427,624 字节；保留 30 个经验证的核心转轴及额外传动层级。
- 几何特征计数：217 处紧固件、57 处轴承、138 个主 / 次传动齿、566 个光学单元、2,406 条翼膜单元边。
- `build_dragonfly.py` 负责装配，`mechanical_geometry.py` 负责薄壳、切削板、车削轮廓、细管和多边形翼脉。生成采用固定随机种子。

## 限制与待验证

- 所有表面使用常量 PBR 材质与真实几何，没有颜色、法线、粗糙度或光照烘焙贴图；GTAO 是运行时效果。
- 刚性对象动画，无骨骼蒙皮；齿轮、推杆与翼根没有工程级机械约束、受力求解或气动模拟。GLB 不包含动画片段。
- 展开是按组件分离以便观察，不代表真实生产装配顺序。
- 第二版增加几何与接触遮蔽开销。移动真机、Safari、触屏手势与长时间帧率 / 显存测试仍待专项验证；窄屏检查不等于真机性能验证。
- 生产 JS 主包约 695 kB（gzip 177 kB），Vite 仍有超过 500 kB 的体积提示。
- 字体使用 Google Fonts，有本地字体回退。当前为本地运行，未远程部署。
