# 当前阶段：夜间可探索世界

用户要求全屏可探索地图，并明确世界是天黑的世界。当前实现保留 Blender → GLB → Three.js 流程，以微弱月光、暖灯和蓝黑战争迷雾呈现真实斜俯视地面空间。

## 已完成

- 48 × 48 米连续地形，隐藏庭院展示底座，复用可编辑源资产，加入森林道路与林间旅舍。
- Blender 提取可复用小屋和树木 GLB；保留原 .blend，不改写源模型。
- 夜间月光、提灯和路灯，移除展示页大标题，改为地图探索界面。
- 镜头平滑跟随人物；拖动临时观察，恢复行走后回到跟随。
- 256 × 256 世界坐标探索网格，出生点揭露半径 5.5 米；按实际移动轨迹增加已探索区域，永久保留。
- 带深度纹理的场景渲染目标与全屏迷雾合成，遮住未知地面、屋顶与树冠；雾缘有软过渡与缓慢噪声。
- 键盘行走、已探索空地点击寻路、分段“沿路向前”；路径不会穿越未知网格。
- 未探索建筑禁止介绍拾取；场景粒子与灯光按揭露状态限制。
- 版本化 localStorage 探索与位置保存；刷新恢复，存储不可用显示提示。
- 回到出生点保留进度；重新探索单独清空进度。

## 验证证据（2026-10-04）

- Blender 提取脚本输出 EXPLORATION_ASSETS_COMPLETE：旅舍 6 个网格，树木 2 个网格。
- GLB 结构、嵌入纹理及原资产转轴检查通过，详见 asset-verification.json。
- 8 项测试通过：导航绕障碍、非法目标、不可达目标、未知区域寻路限制，以及探索单调性、沿途连续采样、地图边界 / 重复揭露、保存版本与损坏数据拒绝。
- Yarn 4.9.1 迁移完成：yarn install --immutable、yarn lint、8 项 yarn test、yarn verify:assets 与 yarn build 均通过；构建仍有 Three.js 包大于 500 KB 的体积提示。Cloudflare 配置与重新部署尚未修改或验证。
- 实际浏览器初始截图只显露提灯人物周围，探索约 3.1%；向前移动后主屋与水井从雾中出现，比例增加至 4.4% 并继续增长。
- 浏览器暂停后探索 8.7%、位置 -8.8 / 0.1 保持不变；旋转相机未揭露新地图；刷新后恢复相同探索比例与位置。
- 沿岔路实际抵达林间旅舍，探索增长至 13.7%，点击旅舍显示正确介绍。回到出生点仍为 13.7%；重新探索恢复出生点和初始 3.1%。
- 浏览器控制台检查无运行错误或 shader 警告。

## 限制与待验证

- 地图有限且全部预加载，未实现区块流式加载或无限世界。
- 揭露按地面距离，不模拟墙壁视线阻挡；没有敌人侦察或离开后重新变暗的第三状态。
- 碰撞为静态矩形；人物仍是对象转轴动画，没有骨骼蒙皮绑定。
- 未烘焙全局光照、法线或粗糙度。没有室内、任务系统或正式角色美术。
- 长时间键盘操作、复杂地图边角、存储容量与移动端性能仍需进一步专项验证。
